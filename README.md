# Novus Lab Homebrew Tap

Official Homebrew tap for [QueryDock](https://github.com/Novus-Lab-Dev/QueryDock) and Novus Lab applications.

## Installation

Add this tap to Homebrew:

```bash
brew tap Novus-Lab-Dev/tap
```

### Install QueryDock

```bash
brew install --cask querydock
```

Or in a single command:

```bash
brew install --cask Novus-Lab-Dev/tap/querydock
```

## Updating

```bash
brew upgrade --cask querydock
```

## Uninstalling

```bash
brew uninstall --cask querydock
```
